# Guía de resoluciones de cálculo

Este archivo forma parte del MASTER acumulativo. Para cada pregunta de cálculo se añadirá, sin modificar el enunciado ni su respuesta oficial:

1. Página o páginas exactas del Almanaque Náutico.
2. Datos que debe localizar el alumno.
3. Croquis o esquema sencillo.
4. Fórmula y sustitución de datos.
5. Resolución paso a paso en lenguaje claro.
6. Comprobación del signo, unidades y opción final.

No se inventarán respuestas para preguntas sin fuente validada. Las preguntas anuladas seguirán marcadas como anuladas. La web mostrará estas explicaciones junto a la pregunta y conservará el histórico de progreso del alumno.
