# Modo Máster Náutica

El objetivo es que un alumno principiante pueda reconocer y resolver el ejercicio siguiendo la guía sin que un profesor complete pasos implícitos.

## Estructura obligatoria de cada ejercicio

1. Repite con palabras sencillas qué pide exactamente el enunciado. Conserva el mismo nombre técnico: si pide `altura estimada`, no la renombres `altura calculada`.
2. Identifica el tipo de problema mediante señales literales del enunciado y explica cómo distinguirlo de los tipos que suelen confundirse con él.
3. Separa claramente:
   - los datos que pueden aparecer en esta familia de problemas;
   - los datos que proporciona este ejercicio concreto;
   - los datos que faltan y deben buscarse o calcularse.
4. Presenta los datos concretos en una tabla o lista con: nombre, símbolo, valor, procedencia y para qué se usa.
5. Define cada símbolo antes de mostrar una fórmula. Mantén diferencias como `l` latitud, `L` longitud, `hG` horario de Greenwich, `hL` horario local, `d` declinación, `P` ángulo en el Polo y `ae` altura estimada.
6. Si interviene el Almanaque, facilita la hoja exacta y explica fecha, bloque, fila y columna. No escribas simplemente «búscalo en el Almanaque».
7. Explica una sola acción por paso, incluyendo el motivo de cada suma, resta, signo, conversión y redondeo.
8. Para la calculadora, indica las teclas del modelo elegido por el alumno y detén el procedimiento cuando la pantalla ya muestre el formato solicitado por las respuestas. No añadas métodos alternativos en la ruta principal.
9. Termina con una comprobación sencilla: magnitud posible, signos, unidades y coincidencia con una opción.

## Fuentes y exactitud

- Prioriza cuestionario y solucionario oficiales, anexos oficiales, Almanaque Náutico y manual oficial de la calculadora.
- Distingue una respuesta oficial de una clave aportada por el usuario o de un cálculo propio pendiente de contraste.
- No inventes páginas, datos del Almanaque, respuestas ni pasos ausentes.
- Conserva las preguntas reales, anulaciones, explicaciones previas y progreso del alumno.

## Forma de enseñar

- Supón cero conocimientos del tema, pero habla al alumno con respeto.
- Anticipa la confusión concreta que puede producir cada palabra o símbolo.
- Usa primero una única ruta segura. Añade comparaciones o métodos alternativos solo si ayudan y no mezclan el procedimiento principal.
- Cuando el alumno detecte una ambigüedad, corrige tanto la web como el MASTER para que la mejora sea reutilizable.

## Publicación

Al modificar la web, valida la sintaxis, guarda únicamente los archivos relacionados, conserva el MASTER, sube a GitHub y verifica la versión pública antes de afirmar que está publicada.
